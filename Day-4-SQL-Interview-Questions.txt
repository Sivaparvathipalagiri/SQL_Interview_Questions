SQL Interview Questions – Day 4

16. What is the OFFSET clause in SQL? 
Interview Answer: OFFSET skips a specified number of rows in a query result, commonly used for pagination. 
Syntax and whether it requires ORDER BY depend on the database. 
Example: SELECT * FROM employees ORDER BY employee_id OFFSET 10 ROWS; 

17. What is a Self Join? 
Interview Answer: A Self Join joins a table to itself. It is useful when rows in the same table have relationships,
such as employees and their managers.
Example: SELECT e.name, m.name AS manager FROM employees e LEFT JOIN employees m ON e.manager_id = m.employee_id; 

18. What is a View in SQL?
Interview Answer: A View is a virtual table defined by a SQL query. 
It stores the query definition rather than normally storing a separate copy of the result data. 
Example: CREATE VIEW high_salary AS SELECT * FROM employees WHERE salary > 50000;

19. What is a Composite Key?
Interview Answer: A Composite Key is a key made from two or more columns that together uniquely identify a row.
 Example: PRIMARY KEY (student_id, course_id).

20. What is the difference between IN and EXISTS? 
Interview Answer: IN compares a value with a list or subquery result. EXISTS checks whether the subquery returns at least one row. 
EXISTS is often useful for correlated checks and can behave differently depending on indexes, optimizer, and data. 
Example: WHERE department_id IN (SELECT id FROM departments); / WHERE EXISTS (SELECT 1 FROM departments d WHERE d.id = e.department_id);
